# SŪRA

Assistant médical intelligent hors connexion pour agents de santé en zones isolées.

## Le problème
Dans les zones isolées, les agents de santé gèrent souvent des dossiers papier et une connexion Internet limitée, ce qui complique le suivi des patients.

## La solution
SŪRA transforme le smartphone de l'agent de santé en assistant intelligent fonctionnant hors ligne : transcription et structuration de la consultation, détection des informations manquantes, suggestion de niveau d'urgence, et synchronisation automatique dès qu'une connexion est disponible.
